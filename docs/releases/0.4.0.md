**Language models, built in.** BERT, neural sentiment and document embeddings now work straight after installing. There's nothing extra to download or set up, and it works offline.

- **Included in the app:** BERT base (word vectors, BERT topics, word senses), DistilBERT (positive/negative sentiment) and Granite Embedding R2 (document embeddings).
- **One-click extra:** Qwen3 Embedding 0.6B (about 570 MB), a stronger embedding model. Download it from the new **Models** page; it stays installed across updates.
- **New tool: document embeddings.** Find documents that are about similar things, see each document's nearest neighbours, view a clustered map of the corpus, and search by meaning rather than exact words.
- **Word meaning over time.** See how the company a word keeps changes across periods.
- **Corpus at a glance.** One button on the **Corpus** page gives a quick overview of your documents: size, key terms, readability, vocabulary variety, tone, the people and places named, and how similar the documents are. It is cached, so it only reruns when your documents change.
- **BERT tools on the Interactive page**, alongside the other live analyses.
- **Clearer tool names.** Every analysis starts with its task, e.g. "Sentiment: …" or "Embeddings: …", so tools that do different jobs no longer look alike.
- **Automatic updates** from this version on (Windows and Mac): NLP Suite offers each new release and installs it with one click. Version 0.3.1 can't update itself, so this one is a manual install. Your projects are kept.

The installer is about 350 MB larger than 0.3.1 because it now includes the models.
