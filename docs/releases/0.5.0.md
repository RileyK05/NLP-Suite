- **Work with document details.** Detect details from file names, import them from a spreadsheet, edit them on the Corpus page, and filter or group analyses by them. A collection can be lined up by date or by an ordered detail such as chapter.
- **Read books by chapter.** Split a long text into chapters or a transcript into speakers or turns. The original moves to Trash by default, and figures for ordered collections use chapter or document positions instead of pretending they are dates.
- **Compare collections.** The new Compare page shows differences in measures, distinctive words, topic prevalence, tone, and words around a chosen focus across two or more document sets. Align by a shared detail or period to compare like with like. Each result records its scope and warns about setting or size differences.
- **Read matching passages.** For two sides and selected focus words, Compare finds closely related sentences and opens both source documents side by side in context.
- **Write analyses in Scripts.** Run local Python notebooks using the suite's library, inspect tables and charts, save a run, and export the notebook with its results. Imported or pasted code is marked for review before running. The app also provides a guide you can copy into a chatbot of your choice; no AI service is built in.
- **Reuse expensive work.** Parsed documents and document vectors can be reused across runs. Settings shows their disk use and can clear these recomputable caches without deleting projects or finished results.
- **Analysis fixes.** Stage directions can be omitted from analysis without changing source files; entity suggestions help remove likely false person names. Date and quote extraction and book figures received corrections. New tf-idf runs omit terms appearing in more than half of documents by default, so their keywords can differ from runs made before 0.5.0. Earlier run results remain intact.
- **Faster SVO analysis.** Subject-verb-object extraction now indexes a sentence's dependencies once, reducing repeated work on long corpora.
