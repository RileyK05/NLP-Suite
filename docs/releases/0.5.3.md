- **Faster on large corpora.** Keyword in context, n-grams, collocations, coreference, dispersion and annotated-word search are rewritten to work on whole columns at once: on a 600,000-word corpus most run ten to a hundred times faster (annotated-word search about twice as fast), with the same results.
- **Tuned to your computer.** The suite now checks how many processor cores and how much memory it has, and sizes parsing batches, parallel work and how many corpora it keeps in memory to match, instead of using one setting for every machine.
- **Quicker to open.** Pages such as Learn, Models and Compare load when you first open them, so the app starts faster.
- **Very large charts draw.** A scatter plot of more than 125,000 points used to fail; it now draws.
- **Scripts is sturdier.** A cell interrupted with Ctrl+C reports its own error instead of ending the notebook, a figure that cannot be saved no longer stops "Run and save", and stray output from a library no longer disconnects the kernel.
- **Command-line parsing is reused.** Running the command-line tools on the same documents with the same parser now reuses the earlier parse instead of parsing again (turn it off with `--no-parse-cache`).
- **Fixes.** A blank cell no longer matches a search for "nan"; keyword-in-context windows no longer include line breaks as words.
- **Updating:** install 0.5.3 over your current version; your projects are kept. One-click in-app updates are not switched on yet.
